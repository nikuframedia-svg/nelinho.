# ProdPlan ONE

**Decision OS for the NELO factory.**

This is the operational documentation site. It is *separate* from the
Python API docs (generated by FastAPI at `/docs` on a running instance)
and from the product marketing site. The audience here is Luis, the
oncall rotation (future), and Nelo IT during DR events.

## What lives here

| Section | When you use it |
|---|---|
| **[SLA](sla.md)** | Monthly review of SLO attainment; before/after incidents. |
| **[Disaster recovery](disaster-recovery.md)** | Quarterly drill; any full-box loss. |
| **[Runbooks](runbooks/index.md)** | Step-by-step response to alerts. |
| **[Plans](24-4.md)** | The current sprint plan (+ historical). |
| **Architecture** | Mental model of each module. Read once, refresh on change. |
| **Governance** | How the learning loop is reviewed in `/admin/learned-rules`. |

## Running locally

```bash
# one-off: install the MkDocs Material theme
pip install mkdocs-material

# serve the docs on http://localhost:8001
mkdocs serve --dev-addr localhost:8001

# build the static site (Caddy serves it on the on-prem box)
mkdocs build -d site
```
